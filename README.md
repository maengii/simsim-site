# LOTTO5 — 실제 배포 가능한 무료 로또 5게임 기록 사이트

- 매주 정확히 **5게임** 무작위 생성. 생성 즉시 `data/rounds.json`에 최초 게시 시각과 함께 고정.
- 토요일 추첨 후 **공식 조회 경로**에서 해당 회차만 받아 번호·보너스·회차 검증 후 대조. 조회 실패 시 **대기** 유지, 절대 가짜 결과를 넣지 않음.
- 이전 기록을 변경하지 않고 아카이브 및 누적 통계 표시.
- Python 표준 라이브러리 + HTML/CSS/JS. 서버/DB/유료 API 없이 GitHub Pages 무료 정적 배포 가능(공개 저장소 기준).

## 1. 로컬 실행

Python 3 설치 후 프로젝트 폴더에서:

```bash
python -m http.server 8000
```

브라우저에서 http://localhost:8000 열기. **HTML 파일 더블클릭이 아니라 로컬 서버를 이용하세요.**

## 2. 운영 자동화 (GitHub Pages)

1. GitHub에서 **새 공개 저장소**를 만들고 프로젝트 파일 전체를 `main` 브랜치에 업로드합니다. `.github/workflows` 숨김 폴더도 빠짐없이 업로드하세요.
2. 저장소 Settings → Pages → Build and deployment → **Source: GitHub Actions**로 설정합니다.
3. Actions 탭에서 `Deploy GitHub Pages` → `Run workflow`로 최초 배포합니다. 이후 `main`에 커밋이 생길 때마다 자동 재배포됩니다.
4. `Lotto 5 weekly update`는 매시간 실행되지만 실제 번호 생성은 **한국시간 일요일 이후** 한 번만 실행합니다. 추첨일 토요일은 **21시 이후** 결과 조회를 시도합니다. GitHub Actions 예약 작업은 지연/누락될 수 있으므로 첫 운영 시 Actions 기록을 확인하세요.
5. 자동 조회가 차단되면 대기 상태로 남습니다. `scripts/lotto.py --manual 회차 번호1 번호2 번호3 번호4 번호5 번호6 보너스`로 공식 발표를 직접 확인한 뒤 결과를 넣고 `data/rounds.json`을 커밋할 수 있습니다.

**중요:** 동행복권은 공식적으로 안정성을 보장하는 공개 API를 제공하지 않습니다. 2026년 개편 후 웹페이지 내부 조회 경로를 사용하며, 서버 접근 제한이나 구조 변경으로 자동 수집이 중단될 수 있습니다. 실패를 감지하면 임의 데이터를 표시하지 않고 결과 대기 상태를 유지합니다. 공식 발표를 수동 확인하는 복구 절차를 남겨두었습니다.

## 3. 최초 데이터

현재 포함된 1244회 5게임은 **2026-10-02**에 새로 생성한 번호입니다. 1243회 이전 과거 결과를 생성한 척하지 않으며 이 회차부터 기록을 쌓습니다. 실제 구매와 무관한 무료 공개 번호입니다.

## 4. 데이터 수정 주의

- 최초 공개한 5게임은 절대 재생성하거나 편집하지 마세요. 기록 투명성을 위해 Git 이력으로 검증 가능합니다.
- 다른 컴퓨터에서 자동화할 때는 저장소 충돌을 피하고, 데이터 파일을 삭제하지 마세요.
- GitHub Pages 배포 경로가 `/repo/`여도 상대경로를 사용하므로 작동합니다.
- 실제 운영 전 사이트 이름, 운영자 연락처, 개인정보/쿠키 처리 여부, 광고 정책은 별도 확인하세요.

## 추가 페이지: 오늘의 황당 운세

`fortune.html`은 별도 서버나 AI API 없이 실행됩니다. 한국시간 날짜와 브라우저별 임의 식별값으로 하루 동안 같은 오락용 결과를 표시합니다. 브라우저 데이터를 삭제하거나 기기를 바꾸면 결과가 달라질 수 있습니다. 선택 해결사와 가챠는 포함하지 않았습니다.
